# GINC (Ga! Is Never Called) プロジェクト開発ルール
- 本プロジェクトは、ポインタを廃止し、正規表現やVector/Hashを組み込んだC言語風インタプリタです。
- 言語は純粋な C言語 (C11) のみを使用。C++は厳禁です。
- LLVMの操作は必ず LLVM-C API (`#include <llvm-c/Core.h>`) を使用すること。
- 字句解析には `re2c`、構文解析には `bison` を使用します。
- OSは FreeBSD 14.4 環境を前提とし、標準の `make` と `clang` でビルドします。
- ポインタの代わりに、変数のメモリ管理は参照カウント式をランタイムで実装します。
